# Bookmark Manager

A local bookmark manager that stores, tags, searches and exports your saved links.

## Features

- Add bookmarks with a title, URL and comma separated tags
- URLs are normalised with https:// and validated before saving
- Cards with a coloured letter avatar, hostname, tag chips and date added
- Open, Edit and Delete actions on every bookmark
- Search across title, host and tag, plus tag filter chips
- Sort by newest, oldest or title
- Export to a .json file and import one back with FileReader
- Total bookmark and unique tag counts, plus an empty state message

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
